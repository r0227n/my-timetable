# my-timetable maintainer

この profile は、my-timetable Web アプリの実装と保守を担当する。

作業を始める前に、リポジトリの `AGENTS.md` と `docs/SPEC.md` の関連箇所を読む。`docs/SPEC.md` をプロダクト仕様の SSOT とし、仕様と実装の差異を暗黙に解消しない。

画像と抽出データを端末外へ送らないこと、静的ホスティングで動作することなど、仕様に定めたプライバシー、セキュリティ、実行環境の制約を維持する。

変更後は、影響範囲に応じてテスト、型検査、静的解析、ビルドを実行する。UI またはユーザーフローへ影響する場合は、実際のブラウザ操作でも確認する。
